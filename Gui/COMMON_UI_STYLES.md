# GM-UI 通用样式

源码运行时，主窗口「重启」下显示 GM-UI；编译运行时不创建按钮，桥接层也拒绝打开编辑器。发布运行仍读取已保存的样式配置。

## 使用

1. 点击 GM-UI，默认选中按钮 A（宏配置操作按钮）。左栏也包含 B/C/D/F、通用控件类型、已加载的命名样式、特殊样式和主题颜色资源。
2. 右侧显示实际控件样式预览、当前属性值、编辑框和使用位置。空白表示继承，输入值后点击「应用预览」。颜色可以输入 `#RRGGBB` 或 `#AARRGGBB`，边距可输入 `左,上,右,下`，宽高支持 `Auto`；尺寸单位为 WPF DIP。
3. 「保存配置」写入 `Setting/CommonUIStyles.xml`；已有文件通过原子替换写入，并保留 `.bak`。关闭编辑器会撤销未保存的预览。「恢复所选默认」清除所选覆盖，保存后才永久生效。
4. 新打开的窗口、动态新增控件和虚拟列表通过公共入口自动接入。打开其他界面后，点击「刷新控件目录」查看它们的实际控件、局部配置和模板。尚未打开的界面只能显示已注册的类型示例，不能据此判断其实际样式。

## 继承规则

配置优先级：`通用/控件类型` → 命名样式或语义角色。配置为空时保留原有主题、布局和模板；明确设置某一属性后，该属性统一作用于组内实例，包括它们原来写在局部的值。数据绑定属性保留绑定，不被通用样式修改。

- 命名资源样式自动按资源键归组，例如 `样式/RmtItemEditBtn`。
- 为业务角色使用稳定的 `Uid="gm:角色名"`，例如 `gm:Main.Save`；生成器写法为 `.Uid("gm:Main.Save")`。不要用窗口标题或宏行号作为持久化样式键。
- 必须保留特殊外观时显式使用 `Uid="gm-exception:稳定标识"`。它会进入「特殊/稳定标识」，跳过类型通用覆盖，但可独立编辑。窗口标题栏按钮自动作为特殊项保留。
- 普通局部配置的原始值、绑定和控件位置可在右侧展开查看；原有模板及触发器也可只读查询。悬停、按下等引用主题资源的颜色在「颜色/资源键」中配置。
- `CornerRadius` 支持 Border；Control 的圆角作用于其模板的第一个外层 Border，保留原模板和交互逻辑。没有 Border 的自绘模板需要自行提供该属性的消费逻辑。

## 接入范围

公共入口是 `XAMLHost`，因此现有 WPF 业务窗口无需逐个调用样式管理器。语音关键词和表管理窗口也已迁移到该入口。GM-UI 自己不接受业务样式覆盖，以保留恢复入口。系统菜单、系统消息框、屏幕选区标记、独立业务浮层及未使用的旧输入按钮实现不属于普通 WPF 控件树，在目录「特殊说明」中登记来源和配置入口。

配置是本机 Setting 数据，不自动修改 AHK 源文件或打包产物。发布时如需携带调好的配置，应将该 XML 一并部署到目标 `Setting` 目录。

## 主题颜色页

主题选项中的颜色配置固定显示 14 个语义颜色槽位，不再按“指令显示、界面浮窗、菜单轮盘、图形节点、通用窗口”分组。所有预设按相同的槽位顺序映射到相同控件用途，预设生成时会保证 14 个色值互不相同，并以两列显示为“颜色1、颜色2……”。修改某个槽位会同步该槽位关联的全部 UI；颜色标签和色块的提示会列出常用用途。

点击色块修改的是该色值对应的全部用途键。主题选项仍保留底层用途键用于兼容旧配置，所以通用窗口、节点、轮盘、浮窗和指令显示会在预览时同步刷新；已打开的界面浮窗和菜单轮盘也使用动态资源立即换色。取消主题窗口会恢复预览前的颜色，点击确定后才写入配置。
